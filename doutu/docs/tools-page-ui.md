# 工具页 UI 重建（对齐 歪点点 4.0.5.39 真机）

> 2026-10-21。设备：V2408A / 1440×3168，参考包 `com.wailian.weishang` 4.0.5.39。

## 1. 以前是什么样

工具页原来贴的是 `assets/tools_ref.png` 一张真机截图，只有 22 个写死的矩形热区
（`TOOL_HOT`），页面不能滚动，截图以外的分组（阿宝 / 小Q / 其它 / 团队相册 / 视频）
根本看不到。

## 2. 现在是什么样

`MainActivity.NativeView` 里整页重画（`drawTools()`），不再用截图：

| 区块 | 说明 |
|---|---|
| 黄色标题栏 | 0–234（设计坐标），`#F9DB61`，居中「工具」 |
| 替换头像 | 单行：168px 图标 + 名称 + 右箭头 |
| 分组标题行 | 168px 图标 + 名称 + 右箭头 + 底部分隔线；点整行进对应模块主页 |
| 4 列网格 | 单元格 264×272.25，图标槽 132、圆底 0.86×，标签 33px，超 4 字按 4 字断两行 |
| 深色模式 | 仅小微组；图标 + 文案 + 开关，状态存 `doutu_tools/dark_mode` |
| 团队暗号 | 仅团队相册组；输入框 + 黄色「确定」，点开弹框输入 |
| 更多功能及教程 | 每组底部胶囊按钮，进 `ToolsTutorialActivity` |
| 滚动 | 整页可拖，最大滚动量按内容高度算；拖动过的手指松手不再误点 |

数据在 `app/src/main/assets/tools_page.json`：

- 六个分组、44 个入口，顺序/名称/图标/跳转目标全部照真机；
- 图标在 `app/src/main/assets/tools_icons/`，是 `_ops/extract_tool_icons.py`
  从真机截图里裁出来、扣掉灰底/白底后的 PNG（48 个，深色模式不留灰边）。

## 3. 入口去向

| 前缀 | 行为 |
|---|---|
| `wechat:<route>` | `WeiHomeActivity` 页内深链（`#/wechat/contacts`、`feature:group-chat`…） |
| `alipay` / `act:*` | 小支/支付宝现有页面（余额、账单、总资产、支付消息、年账单、收款记录、提现、到账声音、淘宝账单…） |
| `tool:avatar/auto/ai` | `ToolImageActivity`（换头像 / 自动替换 / AI 一键模仿） |
| `local:<key>` | `LocalToolActivity`（红包、转账、群发、公众号、已发红包、上传截图、QQ、团队、视频、评论…） |

微信 / 支付宝两类入口已经是现成的微信 / 支付宝复刻页；`local:*` 这批还是原先
的简化本地页，**下一轮按真机截图逐页对齐**（红包、转账、群发助手、公众号、
QQ 主页、团队相册、视频模块）。

## 3.1 小Q 主页（2026-10-21 第二轮）

小Q 分组标题现在进「QQ 主页」而不是微信样式的聊天列表：
`features/qq/QqHomeActivity` 按真机截图重画（1080×2388 设计坐标）——
淡紫页头（头像 / 微笑似年华々 / Q我吧 / 宠物 / 加号）、白卡片里的搜索框、
「添加聊天」、浅灰内容区，底部「消息 / 频道 / 短视频 / 联系人 / 动态」五格
（消息带红色 0 角标）。图标是 `_ops/extract_qq_icons.py` 从真机截图裁出来的
`assets/qq_icons/`。

页内可点：添加聊天 → 本地创建聊天；联系人 / 短视频 / 动态 → 对应本地页。
频道、搜索、宠物图标暂时不动。

## 3.2 红包 / 转账接回微信模块

工具页的「红包」「转账」不再进简化本地页，而是给微信模块加了
`window.__fwOpenToolPay(type)`（`wechat-chat-actions.js`），由
`WeiHomeActivity` 的 `tool:` 路由直达微信那套**发红包 / 转账页**：
金额键盘、祝福语、转账说明、确认弹层都是现成的真实交互。

## 3.3 团队相册 / 视频两个主页（2026-10-21 第三轮）

- **团队相册** → `features/album/AlbumHomeActivity`：黄色标题栏（返回 / 云相册 /
  创建·加入团队）、白底「我加入的团队 3 ›」、灰底提示条、三条特权
  （素材云存储 / 高效一键转发 / 多人共享使用）、右下角黄色加号。
  图标取自真机截图（`assets/album_icons/`）。点「创建/加入团队」「我加入的团队」
  或加号都进本地团队页。
- **视频** → `features/video/VideoHomeActivity`：黑底短视频封面页 ——
  顶部直播/杭州/关注(99)/推荐/搜索，中间黄色加号「上传视频」，右侧头像、
  10000.0w 点赞、10.0w 评论、999 分享、唱片，左下账号与音乐，
  底部首页/朋友/+/消息(99)/我。头像取自真机截图（`assets/video_icons/`）。
  点黄色加号或「抖音 / 微视 / 快手」都进这个页面；「评论切片」仍进本地评论页。

两个分组标题（团队相册、视频）在工具页上点箭头即可直达，已在真机验证。

## 3.4 群发助手 / 上传截图 / 发出的红包（2026-10-21 第四轮）

三个小微组页面按真机重画（`features/wx/`）：

| 页面 | 关键版式 | 交互 |
|---|---|---|
| `MassAssistantActivity` 群发助手 | 浅灰页头（返回 / 群发助手 / 齿轮）+ 空列表 + 底部「新建群发」 | 返回退出；「新建群发」进本地群发页（选联系人 + 内容 + 发送） |
| `UploadImageActivity` 上传截图 | 纯白页 + 黄色加号圆 + 「上传图片」 | 点加号从相册选图，选完按比例显示在页面中间 |
| `SentRedPacketActivity` 发出的红包 | 红色页头（返回 / 发出的红包 / 省略号）+ 灰底统计区（2021年、头像方块、共发出、0.00 元、总数 0 个）+ 白色明细区 | 返回退出；其余为展示 |

头像方块直接从真机截图裁出来（`assets/wx_icons/sentrp_avatar.png`），颜色也取自截图：
页头 `#E36855`、灰底 `#EFEFEF`、年份金色 `#BEA475`、按钮蓝灰 `#58668C`。
